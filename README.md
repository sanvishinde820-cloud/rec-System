# Retail Data Analysis and Recommendation System

## Description
This project performs exploratory data analysis (EDA) and builds recommendation models on online retail data. It includes data cleaning, segmentation, and predictive modeling to generate product recommendations.

## Dataset
The dataset consists of online retail transactions stored in `OnlineRetail.csv` and `cleaned_retail.csv`. Additional analysis notebooks are provided in the root directory.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sanvishinde820-cloud/rec-System.git
   ```
2. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
- Run `app.py` to start the application.
- Execute Jupyter notebooks for detailed analysis.
- Use `recommend.py` to generate recommendations.
